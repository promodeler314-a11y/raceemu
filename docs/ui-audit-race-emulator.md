# UI診断：レースエミュレータ Web（apps/web）

- 診断日：2026-09-19
- 対象：`apps/web/src/` の画面すべて（7つの面、ヘッダ、左の要約、フッタ、通知）
  - CSS は `apps/web/src/index.css` の `@theme`（Tailwind v4.3.3）と、各コンポーネントの Tailwind クラスにある
  - グラフは2種類ある。uPlot（1.6.32）の折れ線（`Charts.tsx` の `Chart`、`MultiRace.tsx`）と、自前の SVG で描くタイム分布（`Charts.tsx` の `TimeHistogram`）と臨界値の分布（`Inverse.tsx`）

  - Playwright（Chromium）で、幅1440px・390px のそれぞれを、明・暗の両テーマで撮影した
  - 学習データ（tessdata）は置いていない。ステータス読み取りが 503 を返す状態も撮影対象にした
  - 個体の保存先はメモリ上（`RACEEMU_DATA_DIR` なし）。Google Fonts への通信は止めていない

## 1. 禁止リストに照らした判定

### 書体

#### システムフォントのスタックを既定フォントとして使わない — 該当

アプリ本体の書体は `index.css:38` の `IBM Plex Sans JP` で、これは問題ない。該当するのは uPlot の部分だけである。

| 画面 | 該当ファイル:行 | 該当パターン |
| --- | --- | --- |
| 詳細・勝率の1本（14・31） | `index.css:2` | uPlot の既定 CSS（`uPlot.min.css`）を上書きせずに読み込んでいる。`.uplot` に `font-family: system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial, …` が指定されている。そのため、グラフの見出し（「速度」「残り体力」「勾配」など、18px 太字）と凡例（14px）が、本文と違う書体で出る |
| 同上 | `Charts.tsx:224-227` | 軸の設定に `font` が無い。そのため canvas に描く目盛りと軸名（「距離 (m)」「時刻 (秒)」）は、uPlot の既定 `12px system-ui, -apple-system, "Segoe UI", Roboto, …` で描かれる |

#### 等幅フォントは数値・コードの表示に限定する — 該当

数値の列や大きな平均タイムに等幅を使うのは妥当である（`Summary.tsx:126` など）。問題は、日本語の語句をまとめて等幅で包んでいる箇所である。

#### 日本語のラベルに欧文前提のスタイルを適用しない — 境界（要判断）

| 画面 | 該当ファイル:行 | 該当パターン |
