# モックと実装のズレ

[UI のモック](../design/README.md)と、動いている `apps/web` を突き合わせた記録である。

**モックを正とする。**
6 面ぶんが `design/*.dc.html` に入っており、Claude Design 側で編集されたものが正である。

対応の欄は次の三つを使う。

- **実装を寄せる**：モックが正しく、コードを直す。
- **モックを直す**：実装の判断のほうが妥当で、モックの側を後で調整する。
- **未決**：どちらが良いか決めきれていない。

| 項目 | モック | 実装 | 対応 |

## 2. 見た目の土台

| 項目 | モック | 実装 |
| --- | --- | --- |
| 色 | CSS カスタムプロパティ（`--ink` `--paper` `--rule` `--surface` `--sunken`）経由 | Tailwind の色クラスを直に |
| 書体 | `--sans` / `--mono` | 指定なし（システムフォント） |
| 角丸 | 3px | `rounded`（6px）が 22 箇所 |
| 区切り | 罫線と余白 | カード（枠線＋背景） |
| ダーク | ヘッダの切替で、トークンをダーク値に差し替える | クラスで両対応（切替の UI は無い） |

**ダークはモックが実装に寄った。** 以前この表では「モックを直す」としていた項目で、いま
モック側に切替が入っている。ただし**やり方が違う**。モックはトークンを差し替える前提で、
実装は `dark:` クラスを 114 箇所に散らしている。トークンに寄せるほうが、以降の面を足すのが楽になる。

## 4. 探索（`Solve.dc.html`）— 新しい面

逆算と組み合わせ探索を 1 枚にまとめた面が増えた。
**計算する中身は既に全部ある。出し方だけが違う。**

| 項目 | モック | 実装 |
| --- | --- | --- |
| 置き場 | 独立したタブ | 設定列の下に 2 つのパネル |
| 逆算の結果 | 達成率の表（現在値に当たる行を強調）＋**臨界値の分布の図**（いまの設定値の位置を破線で） | 表のみ |
| 逆算の但し書き | 見出しの横に 1 行 | パネル内の段落 |
| 実行の内訳 | 「レース 3,660 本・1.42 秒・探し方は二分探索」 | 出していない |
| 探索の内訳 | 「レース 84,000 本・構成の評価 312 回・6.8 秒・4 巡」 | 一部のみ |

## 5. 比較・詳細・エラー

`Compare.dc.html` と `Detail.dc.html` は 1 節・2 節の骨格に載せ替えたうえで、
以前から挙げている中身の差（分布の重ね合わせ、行の群分け、基準列の選択、イベント一覧、
分布内の位置、前後の試行への移動）が残っている。

`Error.dc.html` は新しい面である。
実装には[失敗の見せ方](m8-report.md)（上端の帯と描画の受け皿）があるが、
モックは 1 枚の面として設計している。突き合わせは骨格を入れてからにする。

## 6. 図の色

| 系列 | モック | 実装 |
| --- | --- | --- |
| 速度 | `#2a78d6`（青） | `#2a78d6`（青） |
| 目標速度 | 灰色の破線（文脈色） | `#eb6834`（橙） |
| 体力 | `#eb6834`（橙） | `#1baf7a`（アクア） |

モックの割り当てを採る。
目標速度は速度と同じ量の参照線であって別の系列ではないので、カテゴリ色を 1 枠使うのは割に合わない。
`#1baf7a` は明色面でのコントラストが 3:1 を下回るため、主要な系列に充てるより使用頻度の低い枠に回すほうが無理がない。

## 7. 直す順序

1. **見た目の土台**（2 節）。色をトークンに移し、書体・角丸・罫線を当てる。全画面に効くので、ここが先だと以降の面が楽になる。
2. **画面の骨格**（1 節）。ヘッダのタブ、左の要約レール、実行バー、フッタ。`lg:grid-cols-2` の等分をやめる構造変更になる。
3. **設定の空状態とプリセット**（3 節）。初めて開いた人が最初に当たる。
4. **探索の面**（4 節）。中身は揃っているので、置き場と出し方の作業になる。
5. **設定の入力の形**（3 節）。分割ボタン、補正後の値、コース形状の図。
6. **比較と詳細**（5 節）。
7. **エラーの面**（5 節）と**図の色**（6 節）。

## 8. 積み残し

- **`design/support.js` がリポジトリに無い。** 各 `.dc.html` が `./support.js` を読み込んでおり、
  無いと `DCLogic is not defined` になる。静的な描画はできるので参照には足りるが、
  タブの切替やダークの切替といった動きは確かめられない。
- **`race-emulator-ui.html` が 4 画面のときのまま。** Error と Solve を含んでいない。
  キャンバスとして公開し直すときに再生成が要る（`design/README.md` に注記あり）。
- **モバイル幅は描かれていない。** 実装は幅 390 で横あふれが無いことを `pnpm e2e` で見ているだけである。
